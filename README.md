# Fougasse

**Moteur de memoire persistante locale pour LLM multi-clients via MCP**

Fougasse centralise le contexte entre tous vos clients LLM (Claude Desktop, Claude Code, Cursor, Windsurf...). Plus jamais de copier-coller entre vos conversations IA.

## Fonctionnalites

- Stockage local persistant (zero cloud, zero donnees en transit)
- Serveur MCP compatible avec tous les clients MCP
- Recherche hybride (semantique + BM25 + graphe + temporel)
- Graphe de connaissances dynamique
- Moteur de vitalite cognitif (declin + consolidation)
- CLI d'administration
- Cross-platform : macOS, Windows, Linux

## Installation

```bash
pip install fougasse
```
